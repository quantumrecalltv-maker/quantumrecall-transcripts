# Quantum Recall transcripts

Transcripts of Quantum Recall, the live show hosted by Paul Saurini, as published at https://quantumrecall.tv/transcripts/.

- `episodes/epNN.json` contains `{ep, yt, paras: [[seconds, text], ...]}`.
- The text comes from the episode's YouTube captions, lightly cleaned: filler words and false starts removed, and names and product names corrected.
